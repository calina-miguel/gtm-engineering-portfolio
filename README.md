# GTM Engineering Workbench

This repo is a public workbench for GTM engineering services.

It includes case studies and GTM systems around:

- Outbound campaign systems
- ICP and account scoring
- Prospect research workflows
- Outbound sequence generation
- Reply triage and sales inbox automation
- Case study packaging

## Flagship system

Open `index.html` and start with:

`case-studies/gtm-campaign-cockpit.html`

The flagship sample shows a GTM campaign cockpit that moves from business context to prospect scoring, outreach drafting, and reply triage.

## Positioning

Use this workbench for client discovery calls, GTM engineering service examples, and public work samples.

First sample: a GTM campaign cockpit.

It shows how a sales workflow can move from:

1. Business context
2. ICP and account scoring
3. Prospect list generation
4. Outreach drafting
5. Reply triage

The goal is to turn messy outbound work into systems a founder or sales team can actually test.

## Public access

This project is built as static HTML/CSS/JS, so it can be hosted with GitHub Pages.

Recommended repository settings:

1. Push these files to a public GitHub repository.
2. Go to Settings > Pages.
3. Deploy from the default branch.
4. Use `/root` as the Pages source.
